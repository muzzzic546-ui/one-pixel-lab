What the model can't see 🙈

You see colors. The model gets only two brightness numbers, so to it every outfit is in shades of gray. It never knows whether something is navy, maroon, or neon green. That means it can get fashion badly wrong:

💡 Takeaway: the model is only as smart as what it measures. It measures a gap between two numbers, not taste, hue, or style. To judge real clashes it would need more inputs, like the actual hue of each color.
